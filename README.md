# AI-Generated Image Detection Using DINOv3

## 📌 Project Overview

This project explores the detection of AI-generated images using **DINOv3**, a pretrained Vision Transformer developed by Meta.

The goal is to classify images into two categories:
- **Real (0):** Human-created images.
- **AI-generated (1):** Images generated by artificial intelligence.

Two approaches are investigated: using DINOv3 as a frozen feature extractor with lightweight classifiers, and fine-tuning the entire DINOv3 model for the classification task.

## 🧠 Methodology

The project follows these main steps:

1. **Dataset Exploration & Preparation:** Analyze the dataset, inspect labels, check image properties, and create stratified training, validation, and testing splits (70/15/15).
2. **Feature Extraction:** Extract 768-dimensional feature vectors from images using the frozen DINOv3 model.
3. **Classifier Training:** Train and compare Logistic Regression and a PyTorch linear classifier.
4. **Model Evaluation:** Evaluate performance using Accuracy, Precision, Recall, F1-score, ROC-AUC, and confusion matrices.
5. **Generalization Testing:** Test the trained models on CIFAKE without retraining to evaluate their ability to generalize to another dataset.
6. **Fine-Tuning:** Unfreeze the DINOv3 backbone and train the full model end-to-end, then compare its performance with the frozen approach.

## 🚀 Getting Started

The project was developed using **Kaggle Notebooks**.

To run it:
1. Open the notebook in Kaggle.
2. Enable GPU acceleration for faster training.
3. Add the required datasets.
4. Configure your Hugging Face access token (`HF_TOKEN`) in Kaggle Secrets.
5. Run the notebook cells sequentially.

## 📊 Results

The project compares:
- Frozen DINOv3 + Logistic Regression.
- Frozen DINOv3 + PyTorch Linear Classifier.
- Fine-tuned DINOv3.

Performance is evaluated on both the main test set and the external CIFAKE dataset. Results, comparison tables, confusion matrices, ROC curves, and learning curves are generated in the notebook.

## 🎯 Objective

The main objective is to investigate how well pretrained visual representations from DINOv3 can distinguish real images from AI-generated ones, and whether fine-tuning improves detection performance and generalization to unseen datasets.
